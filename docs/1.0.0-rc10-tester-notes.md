# InstantJPDict 1.0.0-rc10 — tester notes

This release fixes the placement of a line-ending closing mark.

## Fixed

- **A line-ending 。/closing bracket no longer draws over the previous
  character.** The final fullwidth closing mark (。、，）」』】〙〗〟’”］)
  now takes the advance cell after its predecessor, and the predecessor is
  extended to the shared boundary so the line still tiles. This matters when
  the detection crop ends at the mark's ink rather than at its cell.
  The raw `CharPlacement.place` path remains the Python reference; the page
  path applies the new post-pass.
- Includes the CTC space-run collapse already on `master`.

## Known

The `recognition-01-tategaki-fonts` "た的めしがき" text drift is
pre-existing and unchanged; it is not a regression in this release.

## Update

Obtainium should offer rc10 as an update from rc9: versionCode 10, same
signing key, prereleases enabled. The rest of the setup and known
limitations are unchanged.
