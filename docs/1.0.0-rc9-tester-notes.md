# InstantJPDict 1.0.0-rc9 — tester notes

This is a bug-fix release for Jitendex old-kanji redirects.

## Fixed

- **Old-kanji redirects now resolve.** Jitendex marks rows such as 說教
  with a `redirect-glossary` wrapper. The redirect extractor treated that
  wrapper as real definitional content, so the lookup stopped at the
  `⟶ 説教` stub. The shared rule now recognises the wrapper; the panel shows
  the 説教 entry below the pointer. The pinned Jitendex 2026.08.11.0 archive
  has 138,529 rows using this class.
- Regression coverage: the real 說教 payload in `DictionaryRedirectsTest`
  and the shared Rust `definition_format` unit tests.

## Update

Obtainium should offer rc9 as an update from rc8: versionCode 9, same
signing key, prereleases enabled. The rest of the setup and known
limitations are unchanged from rc8.
