# InstantJPDict 1.0.0-rc8 — tester notes

This is the **Obtainium/update** release: the OCR and dictionary behaviour is
unchanged from 1.0.0-rc7, but the native backend and the release channel are
new.

## What changed since 1.0.0-rc7

- **Obtainium support.** Install and update directly from this repo's GitHub
  releases. The README badge adds the repository with prereleases enabled, or
  add `https://github.com/holopengin/InstantJPDict` in Obtainium and enable
  **Include prereleases**.
- **ncnn rebased onto upstream.** The vendored ncnn fork now sits on
  `Tencent/ncnn@437f18f7` with the five required fork patches. Host and Pixel
  7a arm64 smoke tests pass; `rec_dyn` output is byte-identical to rc7, and the
  detector float drift is ~1.4e-7.
- **Release plumbing.** A tag-driven `Release APK` workflow verifies the
  production package id, the version, and the release-key fingerprint before
  uploading. The stale checked-in release APK was removed.

## Install

The app is arm64-v8a only and requires Android 11 or newer. Install the
dictionary first (**Jitendex** recommended), then enable the accessibility
service and use the accessibility button to capture. The full setup and
trigger instructions from rc7 still apply.

## Known limitations

- Vertical text and unusual layouts are the weak spot.
- The ruby/furigana filter is off by default; **Debug settings** has the
  per-mode switches.
- The experimental tree-sourced modes can misdraw lines with mixed font sizes.

## How to report

Use the **Have Feedback?** button in the app, or write to
**holographicpengin+InstantJPDict@gmail.com** with the phone model, Android
version, what you were reading, and what happened.
